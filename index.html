Breakdownschets

Wat is een breakdownschets?

Een breakdownschets is een schets met codes voor een webpagina. Deze codes zijn gekoppeld aan HTML en CSS door middel van verschillende kleuren. De schets moet niet helemaal gedetailleerd zijn, maar een wireframe.

Vragen

  2. Waar moet je op letten als je een breakdownschets maakt?
  3. Moet je bij een breakdownschets altijd alle onderdelen tekenen?
  4. Hoe zorg je ervoor dat een breakdownschets overzichtelijk blijft?
  5. Hoe kan ik mijn ontwerp vertalen naar HTML en CSS?

UX van HTML

Tijdens deze les heb ik geleerd hoe verschillende HTML-elementen bijdragen aan de gebruiksvriendelijkheid en toegankelijkheid van een website.

Links

  • <a>: Een link gebruik je om te navigeren naar een andere pagina of URL.
  • <button>: Een button gebruik je voor een actie op de pagina.

Afbeeldingen en formulieren

  • Afbeeldingen moeten een goede alt-tekst hebben.
  • Bij elke <input> hoort een <label>.

Labels

  • Zorgen voor duidelijkheid: wat is wat?

Headings

  • Zorgen voor een duidelijke structuur op de pagina.

Details

  • Hiermee kun je widgets maken, zoals een accordion (uitklapbare onderdelen).
